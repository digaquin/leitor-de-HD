# AgroEstoque

Aplicação web estática para acompanhar estoque de defensivos agrícolas por lote, validade, princípio ativo, quantidade e status operacional.

## Executar localmente

```bash
npm run dev
```

Depois acesse `http://localhost:5173`.

## Gerar build estático

```bash
npm run build
```

O comando copia os arquivos da aplicação para `dist/`, que pode ser servido por qualquer servidor estático.
